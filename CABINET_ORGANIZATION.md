## 2. Thematic Organization Overview

The cabinet is divided into logical wings and dedicated zones:
1. **American Whiskey Wing (Doors 1 & 2)**: 32 bottles encompassing Kentucky straight bourbons, craft heritage corn/wheat/oat expressions, and bold rye whiskeys.
2. **The Westland & American Single Malt Sanctuary (Doors 3, 4 & 5)**: 48 bottles dedicated to the premier craft category. Spotlights the remarkable 39-bottle Westland library (core expressions, single casks, handfills, Colere editions, Peat Week vintages, and local brewery/winery Cask Exchanges), flanked by craft innovators like Copperworks, Whiskey Del Bac, and Virginia Distillery Co.
3. **The Global Peat & Grain Library (Doors 6 & 7)**: 32 bottles featuring the smoky Islay titans (Ardbeg, Bruichladdich, Port Charlotte), Highlands/Islands classics, Japanese masters (Nikka, Suntory, Ichiro's), and rare craft collaborations.
4. **The Trophy & Sun-Belt Spirits (Door 8)**: 16 bottles housing the vaulted "Unicorns" (Yama Mizunara, Hakuro, Kavalan Solists, Hibiki 17, Toasted Bourbon), fine French Cognac, artisanal Mezcals/Tequilas, and island rums.
5. **The Cocktail & Botanical Atelier (Cubbies 1–4)**: 40 bottles in 10-bottle cubbies, keeping 20 craft gins and 20 amaros/vermouths immediately accessible for cocktail mixing and aperitifs.

## 5. Software Suggestion: Drink Data File (`scripts/drinkdata.js`)

To record physical locations in [`scripts/drinkdata.js`](file:///c:/Users/asabb/OneDrive/Desktop/liquor-cabinet/scripts/drinkdata.js), add a concise `location` string attribute to each drink object:

```javascript
// Example in scripts/drinkdata.js:
{
    distillery: 'Westland',
    bottle: 'Colere 1st Edition',
    region: 'Washington, USA',
    ABV: '50%',
    age: '4 Years',
    location: 'D4-S2',  // Door 4, Shelf 2 (Bottom)
    notes: 'Made with Skagit Valley Malting Alba Barley',
    occasion: 'Promotion to Director - March 2024',
    retired: '',
    peated: '',
    cask: '',
    other: ''
}
```

### Location Code Syntax:
- `D<1-8>-S<1-2>`: Door (1 to 8), Shelf (`S1` = Top, `S2` = Bottom). Example: `D1-S1`, `D5-S2`.
- `C<1-4>`: Cubby (1 to 4). Example: `C1`, `C3`.
- Optional slot index: Append `-P<1-10>` if you wish to track left-to-right position (e.g. `D4-S1-P3`).

### Helper Parser (`scripts/drinkdata.js` or `scripts/liqourcabinet.js`):

```javascript
function parseCabinetLocation(locCode) {
    if (!locCode) return null;
    if (locCode.startsWith('D')) {
        const [doorPart, shelfPart] = locCode.split('-');
        const door = doorPart.replace('D', '');
        const shelf = shelfPart ? shelfPart.replace('S', '') : '1';
        return {
            type: 'door',
            code: locCode,
            door: parseInt(door),
            shelf: parseInt(shelf),
            shortLabel: `Door ${door} · ${shelf === "1" ? "Top" : "Bottom"}`,
            fullLabel: `Door ${door}, ${shelf === "1" ? "Upper Shelf" : "Lower Shelf"}`
        };
    } else if (locCode.startsWith('C')) {
        const cubby = locCode.replace('C', '');
        return {
            type: 'cubby',
            code: locCode,
            cubby: parseInt(cubby),
            shortLabel: `Cubby ${cubby}`,
            fullLabel: `Cubby Compartment ${cubby}`
        };
    }
    return { code: locCode, shortLabel: locCode, fullLabel: locCode };
}
```
